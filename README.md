# Reactive_Programming_ExampleMy

Лабораторна робота №2. Частина I — прив’язка даних в Angular 22.

```sh
npm ci
npm start
```

Відкрийте http://localhost:4200/. На сторінці відображається кількість товарів із репозиторію. Команда `npm run build` створює збірку та попередньо генерує головну сторінку.
